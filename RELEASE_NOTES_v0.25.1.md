# F6 Club Manager v0.25.1

## Refined

- Player assessments remain fully available in Club Mode.
- Club Mode now hides Coach recommendation and Suitable teams because these are recruitment-only controls.
- Club Mode assessment history shows the saved coach and scores without displaying old trial recommendations.
- Ratings, automatic average, strengths, development areas, saving and progression remain available in both modes.

## Compatibility

- Existing recommendations and suitable-team selections are preserved rather than deleted.
- Turning Trials Mode back on restores those controls and their existing values.
- No Firebase rules, database migration or GitHub secrets need to change.
